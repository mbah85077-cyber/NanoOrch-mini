# NanoOrch Mini V2
An offline, self-learning AI built in Python that runs directly on Android (Termux).

Features:
- Learns new topics with 'add' command
- Answers networking: TCP, UDP, bus/star/ring topology, OSI model, router, switch
- Runs 100% offline, no API needed
- Built for students learning AI on phone

Built by mbah85077-cyber
Run: python brain.py
